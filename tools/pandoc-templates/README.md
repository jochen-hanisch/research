# Pandoc Templates

Dieser Ordner enthält den kuratierten Bestand aus dem früheren CloudDocs-Ordner `pandoc-templates`.

## Struktur

- `templates/`: Markdown-/Obsidian-Vorlagen und ältere RTF-gespeicherte Kompilierungshilfen.
- `styles/`: CSL- und Stilmaterial.
- `bibliography/`: Beispiel- beziehungsweise Altbibliografie.
- `media/`: begleitende Medien früherer Template-Stände.

Aktive Lua-Filter für Builds liegen nicht hier, sondern unter `../pandoc/`.
